# MAXX Cartridge — Product, Pitch, and Go-To-Market

## Product
MAXX Cartridge is a portable, offline-first AI workspace delivered on removable storage. The same agent identity, memory, skills, projects, user files, model inventory, recovery manifests, and sync journal can travel between supported hosts. USB remains the desktop delivery format; microSD is the Android sidecar format.

## What the customer buys
Not a memory card and not a chatbot. They buy a **portable digital worker and private workspace** that continues to function without a cloud connection and can synchronize verified changes when connectivity returns.

## Reference offer
**MAXX Pocket Pilot**
- Preconfigured high-endurance microSD or USB 3.x media.
- Agent Max cartridge initialized for one user/workflow.
- Safe old-card import process that copies first and never modifies the source.
- Local file organization, lightweight coding/workspace operations, journaling, snapshots, and offline queue.
- Optional encrypted cloud/desktop sync setup.
- Recovery manifest and export instructions.

## Pitch
**Your AI, memory, projects, and files travel with you.** MAXX works locally from removable storage, keeps a recoverable record of changes, and hands difficult or connected work to your desktop/cloud only when available. USB for computers; microSD for Android; one portable agent state.

## Buyer to prove first
Field worker, freelancer, small-business owner, or technically capable operator who has an Android phone with microSD and values offline access, file backup, and portable work more than frontier-model chat quality.

## 30-day commercial path
1. Sell 5 paid pilots before native Android development.
2. Deliver the first pilots using the existing USB runtime plus Termux microSD sidecar.
3. Record the top three repeated jobs customers actually use offline.
4. Build the native Android shell only around proven repeated jobs.
5. Upsell optional MAXX Cloud Sync / MAXX Operations after local value is proven.

## Pricing hypothesis to test
- **Pilot setup:** hardware cost + setup/service margin, sold as a one-time configured cartridge.
- **Cloud Sync:** optional recurring subscription for encrypted backup, remote compute, and cross-device continuation.
- **Operations:** higher recurring tier for managed automations, monitoring, and business workflows.

Do not finalize pricing until the first five paid pilots reveal support burden, hardware failure rate, average storage use, and cloud-compute consumption.

## Distribution
- Direct demonstrations: airplane-mode proof, edit/create work, reconnect, sync.
- Existing small-business/nonprofit relationships first; no broad consumer launch.
- Sell the outcome and ownership model, not parameter counts.

## Demo script
1. Insert/mount cartridge.
2. Start Agent Max from USB or Android sidecar.
3. Turn off network.
4. Find a project and modify a file.
5. Import a sample old-card folder without altering it.
6. Generate snapshot and sync plan.
7. Restore network.
8. Push/hand off the verified delta to desktop/cloud.
9. Show the same Agent Max identity/state on the second host.

## Product gates before mass sale
- Native Android permission UX.
- Encryption-at-rest for portable secrets and sensitive memory.
- Conflict-tested bidirectional sync.
- Card-removal/power-loss recovery tests.
- Supported-card matrix and counterfeit-card detection guidance.
- Backup restore drill.
- Clear customer-data responsibility terms reviewed by counsel.
